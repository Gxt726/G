1 背景与目标

观察到的问题

广告变现型休闲小游戏市场存在一个普遍矛盾：想要高广告填充率以提升收益，却又怕过度打断体验导致用户流失。许多产品要么广告植入生硬、体验割裂，要么过于依赖用户点击触发广告，造成"误触广告-被迫观看"的负循环。

我们的产品决策

打造一款以激励视频广告为唯一广告形式、以用户主动选择为唯一触发方式的合成类小游戏。通过精心设计的"游戏困难时刻"和"奖励诱惑时刻"，让用户出于自身意愿主动选择观看广告换取收益，形成"广告观看 → 游戏奖励 → 更久游玩 → 更多广告机会 → 分享传播"的正向循环。

目标（可观测结果）

  • 用户进入游戏后能在 10 秒内理解核心玩法，30 秒内完成首次合成
  • 游戏结束时，至少 40% 的用户主动选择观看广告复活
  • 单用户日均广告观看次数 ≥ 2 次，人均广告收益 [TBD] 元
  • 分享率 ≥ 15%，带来的新用户占比 [TBD]
  • 次日留存 ≥ 25%，7 日留存 ≥ 10%

3 核心产品模型

核心玩法概述

合成小星球是一款 2D 合成类物理休闲游戏。玩家在一个容器内释放星球，相同等级的星球发生碰撞会合成更高级的星球。游戏目标是合成尽可能高等级的星球，获取高分，最终合成传说中的"终极星球"。

玩法融合：合成大西瓜的物理掉落 + 2048 的合成升级逻辑 + 轻度收集养成。物理效果带来视觉快感，升级合成带来成就感，收集解锁提供长期目标。

4 功能需求

FR-01 核心玩法模块

目的

让用户在 30 秒内上手，在 3 分钟内获得第一次合成的成就感，形成"再来一局"的冲动。

布局

  • 顶部 HUD：当前分数、金币数量、"下一个星球"预览指示
  • 中间主游戏区：一个带物理引擎的容器，星球在其中自由堆叠和合成
  • 底部操作区：释放星球按钮、设置按钮

触发与流程

  1. 游戏启动后，系统随机生成当前可释放星球（等级 1–3）
  2. 用户手指/鼠标点击游戏区某位置，该星球从顶部对应位置释放
  3. 星球自由下落到容器底部，与其他星球堆叠
  4. 当两个相同等级的星球碰撞时，合成一个更高等级的星球（体积更大）
  5. 合成时产生视觉/动画特效，并播放合成音效
  6. 游戏区顶部有一条"失败线"：任何星球超过此线并保持 3 秒，游戏结束

FR-02 持续留存与成长养成

目的

给用户提供"每天回来"的理由，把一次性玩家转化为回访用户。

功能清单

每日签到

  • 连续签到 1–7 天递增奖励：金币、起始等级加成、合成几率加成等
  • 第 7 天固定奖励：随机道具包
  • 断签重置连续天数，但基础签到仍可领取
  • 看广告可加倍签到奖励

星球图鉴

  • 展示所有 10 种星球的 2D 卡片，未解锁的显示为剪影 + "???"
  • 用户首次合成某星球时自动解锁图鉴，解锁时弹出庆祝动画
  • 收集满 10 种星球 = 成就达成 → 可分享的"星球大师"海报
  • 图鉴进度百分比常驻显示，提供长期目标

金币与道具系统

道具名称 效果 获取方式 广告触发点
清除道具 清除游戏区中最低等级星球 签到奖励 / 看广告获取 游戏进行中弹出"清除危险星球"提示
冻结道具 5 秒内星球不移动、不坠落 签到奖励 / 看广告获取 即将触发失败线时推荐使用
升级道具 下次释放的星球等级 +2 看广告获取 手动触发 "看广告拿升级"
双球道具 一次释放两个相同星球 看广告获取 手动触发

限时挑战模式（P1）

  • 每日 1 个挑战目标（如 "合成 ★5 熔岩星"、"一局获得 3000 分"）
  • 完成挑战获得额外金币 + 可分享的成就徽章
  • 周末特殊挑战：双倍奖励

FR-03 激励广告与奖励系统

目的

把广告观看变成用户"想要做"的事，而非"被迫忍受"的事。关键是让广告触发时机刚好出现在用户想要得到某些东西的时候。

核心原则

  1. 用户主动触发：没有任何自动弹出、倒计时强制、假关闭按钮等
  2. 明确告知：触发前清晰展示"广告时长 → 获得什么奖励"
  3. 即时发放：广告播放完成后奖励立即到账，有视觉确认
  4. 有限频率：单局内广告次数上限 [TBD]；两次广告间有 ≥ 60 秒冷却 [Assumption]

FR-04 分享传播与邀请

目的

让用户"想要分享"，而不是"被要求分享"。分享应该成为炫耀、求助、娱乐的自发行为。

核心原则

  1. 不强制分享：任何场景下分享都不是解锁内容的前提条件
  2. 分享有回报：被分享者和分享者都能获得好处
  3. 一键操作：简化分享流程，减少操作环节

分享场景与触发

场景 时机 分享内容 分享动力 P0/P1
成绩炫耀 游戏结束时 战绩海报（合成到最高星球 + 分数）+ 小游戏入口链接 "我合成了红巨星！你能合成什么？" P0
图鉴解锁 首次解锁新星球时 星球卡片 + 解锁提示 + 小游戏链接 "看看我新发现的星球！" P0
求助邀请 游戏进行中即将失败 "帮我看广告清除一排" → 好友点击后，分享者获得一次清除道具 "兄弟救我一把！" [Assumption] P1
每日任务 挑战完成后 成就徽章 + 小游戏链接 "每日挑战达成！" P0
终极目标 合成终极星时 专属庆祝动画 + 全图鉴海报 "我达成了终极成就！" P0

分享后奖励规则

  • 好友完成首次合成高等级星球 → 分享者额外获得道具包奖励
  • 奖励每日结算上限 [TBD，建议 300 金币/天]

收益测算（假设场景）

测算假设

  • eCPM ≈ 80 元/千次观看（国内激励视频广告中位水平） [Assumption, TBD]
  • DAU = 10,000（种子用户期）
  • 人均广告观看 = 2.5 次/天
  • 广告填充率 = 85%
  • 次月 DAU = 50,000（增长期）
单次广告观看收益（净） 0.08 元/次（eCPM 80 ÷ 1000）
DAU = 10k 时 · 日均收益 10,000 × 2.5 × 0.08 × 0.85 = 1,700 元/天
DAU = 10k 时 · 月均收益（30 天） = 51,000 元/月
DAU = 50k 时 · 月均收益（30 天） = 255,000 元/月

数据来源说明：

  • eCPM 数据来自 [TBD] 广告平台 2025 Q4 休闲游戏品类激励视频广告中位 eCPM；
  • 留存、人均时长等指标为假设目标值，待上线后实测；
  • 收益测算未扣除平台分成（微信小游戏平台抽成比例 [TBD]），实际收入需按平台规则调整。

验证方法

  1. 进入 → 体验：监测 "进入首页 → 首次合成" 的转化漏斗，判断玩法是否易上手
  2. 体验 → 留存：DAU/MAU 比例、次日/7日留存、日均游玩时长
  3. 留存 → 广告：广告参与率（游戏结束时选择看广告的比例）、广告完成率、人均广告观看次数
  4. 广告 → 收益：eCPM、人均广告收益（ARPU-ad）、每日广告总收入
  5. 收益 → 传播：分享率、分享带来的新用户占比、新用户次日留存
